# Security Policy

## Supported versions

Security fixes apply to the `main` branch and the latest tagged release.

## Reporting a vulnerability

Please report security issues privately through GitHub Security Advisories:

<https://github.com/dawidsok/dim-sum-theme/security/advisories/new>

If advisories are unavailable, open an issue with minimal details and ask for a private contact path. Please do not disclose exploit details publicly until a fix is available.

## Dependency posture

Dim Sum has no runtime dependencies. Development checks use npm's lockfile and `npm audit` in CI.
